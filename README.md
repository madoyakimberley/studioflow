# StudioFlow

**The Operating System Freelancers Need**

Stop wasting time on project setup, client communication, and deployment. StudioFlow handles it all — so you can just code.

---

## The Problem

You've been there:
- **Friday 4 PM:** Client approves the initial mockup
- **Monday 9 AM:** You're unsure what folder structure to use, if it should be a monorepo, which dependencies to install...
- **2 weeks later:** Final presentation. Client looks at the site and says: *"Wait, where are the brand details we discussed? This doesn't match what I asked for."*

Meanwhile you're thinking: *"They saw this two weeks ago when we shared the link. They approved it."*

The real issue? **Communication broke down.** The client didn't have visibility into what you were building. You were guessing what they wanted. Nobody won.

StudioFlow solves this.

---

## What It Does

### 1. **Kill Project Setup Friction**
Stop asking "what folder structure should I use?" or "do I need a monorepo?" 

One command generates a production-ready project scaffold with:
- Proper folder structure (based on your standards)
- Next.js + TypeScript + Tailwind pre-configured
- GitHub/GitLab repo created automatically (private)
- Environment variables pre-set
- All best practices baked in

**Result:** You start coding in 2 minutes instead of 30.

### 2. **Real-Time Client Visibility (The Game Changer)**
Your client gets a private dashboard where they can:
- See live previews of your work — *as you build it*
- Check deployed sites in real-time
- Approve components, pages, features one by one (no more last-minute rejections)
- Upload brand assets and details in one place
- See error alerts if something breaks in production
- Message you directly with feedback

**Your client never again gets to say:** *"I didn't know what was being built."*

**You never again hear:** *"This doesn't match what I asked for."*

### 3. **One-Click Deployment**
Push your code → it auto-deploys to:
- **Render** 
- **Vercel**
- **Railway**

Your client sees it live immediately. No manual deploy steps. No "wait, is it on production yet?"

### 4. **Seamless Communication**
Everything lives in one place:
- Project progress
- Client approvals
- Asset management
- Chat & requests
- Deployment status

No more scattered emails, Slack threads, and spreadsheets.

## How It Works

**For You (Developer):**
1. Create a workspace on StudioFlow
2. Install the CLI (`npm install -g studioflow`)
3. Create a new project → folder structure + GitHub repo created automatically
4. Code your app
5. Push to GitHub → auto-deploys to Render/Vercel/Railway
6. Your client sees it live in their dashboard, approves it, you move on

**For Your Client:**
1. You send them a link with a 6-digit code
2. They click it → their private dashboard loads
3. They see your work live, upload brand assets, send messages
4. They approve work, you deploy the next feature
5. No surprises. No miscommunication.

## Tech Stack

Built with modern, proven tools:

- **Frontend:** Next.js 16, TypeScript, Tailwind CSS, shadcn/ui
- **Monorepo:** Turborepo + pnpm
- **Database:** Drizzle ORM + MySQL / Supabase
- **Backend:** FastAPI (Python) — planned
- **Deployment:** Render, Vercel, Railway integrations
- **Form Validation:** Zod, React Hook Form
- **Icons:** Lucide React
- **Animations:** Framer Motion
