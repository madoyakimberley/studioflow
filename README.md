# StudioFlow

**My Personal Freelance Developer Operating System**

A powerful internal system I built to bring consistency, transparency, security, and professionalism to every client project.

### Philosophy
I believe great development is not just about writing code — it's about **clarity, security, repeatability, and trust**. StudioFlow enforces my development standards on every project.

### Core Features

- **Smart Project Generator** — CLI + Web Wizard to spin up production-ready projects
- **Client Transparency Dashboard** — Clients can see real-time progress, live previews, security status, and testing results
- **Modular Architecture** — Easy to swap providers (UploadThing, Supabase, etc.)
- **Built-in Best Practices** — Security checks, proper validation, CI/CD, testing setup
- **Hybrid System** — Powerful CLI + Beautiful Web Dashboard

### Tech Stack

- **Monorepo**: Turborepo + pnpm
- **Frontend**: Next.js 16 + TypeScript + Tailwind + shadcn/ui
- **Backend**: FastAPI + Python (planned)
- **Database**: Drizzle ORM + MySQL / Supabase
- **File Uploads**: UploadThing
- **Other**: Zod, React Hook Form, Lucide Icons, Framer Motion

### Current Status
- CLI orchestrator working
- Web Dashboard MVP in progress
- Project scaffolding active

### How I Work
Every project follows a strict, thoughtful process:
1. Clear requirements & scope agreement
2. Professional project initialization
3. Iterative development with continuous testing & security checks
4. Transparent client updates via StudioFlow
5. Thorough handover + documentation
